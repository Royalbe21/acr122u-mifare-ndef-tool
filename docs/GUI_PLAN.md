# GUI Plan

## Goal

Turn the working CLI into a simple Windows desktop app for writing NFC business cards.

## v0.2.0 GUI goals

- Reader selector
- Card scan panel
- UID display
- Existing NDEF display
- Preset selector
- URL / phone / email / text writer
- One-click write
- One-click format + write
- Success/failure activity log
- CSV logging through the existing core

## v0.3.0 GUI goals

- Guided batch mode
- Card remove/insert detection
- Progress counters
- Failed-card retry workflow
- Safer overwrite review screen

## v0.4.0 goals

- PyInstaller `.exe` packaging
- GitHub Actions build artifact
- Versioned releases
- Installer or portable ZIP
